## ПРОЕКТ ЛАМОР-1 «ГАВИАЛ»

Многоцелевой самолёт-амфибия собственной разработки, предназначенный для мониторинга и тушения лесных пожаров в труднодоступных регионах РФ с минимальной зависимостью от наземной аэродромной инфраструктуры.

> Ежегодно в РФ сгорает от 2,5 до 16 млн га лесного фонда. 65% территории страны не имеет развитой аэродромной сети — именно для этих условий спроектирован ЛАМОР-1.

## 3D-МОДЕЛИРОВАНИЕ

**Инструментарий:** Blender 4.5.4

Процесс создания модели (снизу вверх):
1. Днище и корпус-лодка: V-образная форма с одним реданом и интегрированными спонсонами
2. Фюзеляж: надстроен на основе корпуса-лодки
3. Центроплан: единое целое с фюзеляжем
4. Крыло: с механизацией (предкрылки, закрылки, флапероны)
5. T-образное хвостовое оперение с рулями
