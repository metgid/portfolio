## ИНДИВИДУАЛЬНЫЙ ИНЖЕНЕРНЫЙ ПРОЕКТ

### ЛАМОР-1 «Гавиал»

Многоцелевой самолёт-амфибия для мониторинга и тушения лесных пожаров в труднодоступных регионах РФ. Итоговый индивидуальный проект за 2024–2025 учебный год.

**Научные руководители:**
- Крыжановская Т. Д. — учитель физики
- Орлова С. П. — учитель информатики

```
┌─────────────────────────────────────────────────────────┐
  │  Задача: спроектировать гидросамолёт, способный        │
  │  конкурировать с Бе-200 и CL-415 по эффективности,    │
  │  но со значительно меньшей стоимостью эксплуатации.    │
  └─────────────────────────────────────────────────────────┘
```

### Что было сделано в рамках проекта

1. **Анализ нормативной базы** — АП-25, ГОСТ Р 54076-2010, ФАП-128
2. **Выбор материалов** — АМг6, Д16Т, углепластик, сталь 30ХГСА
3. **Аэродинамический расчёт** — поляра крыла, крейсерский и взлётный режимы
4. **Прочностной расчёт** — весовая сводка, проверка на перегрузку n = 3,0
5. **3D-моделирование** — полная модель в Blender (корпус-лодка, крыло, T-оперение)
6. **Визуализация обтекания** — Geometry Nodes, Particle System, Streamlines
7. **Прототипирование** — масштабный макет 1:71 методом FDM 3D-печати
8. **Верификация** — сравнение с Dornier Seastar (отклонения ≤ 5,1%)

## ПОЧЕМУ АВИАЦИЯ

> Меня привлекает авиация как область, где инженерное мышление, дисциплина и человеческий фактор работают в единой системе. Особый интерес вызывает санитарная авиация — возможность сочетать профессиональные навыки пилота с помощью людям в критических ситуациях. Работа над проектом ЛАМОР-1, посвящённым тушению лесных пожаров, укрепила это стремление: я увидел, как авиатехника решает реальные задачи на масштабе всей страны.
