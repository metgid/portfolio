## ПРОЕКТ LAMOR-1

**LAMOR-1** — радиоуправляемый самолёт собственной разработки с интегрированными системами автопилота, GPS-навигации, телеметрии и видеопередачи.

### Интегрированные системы

- Автопилот — настройка и калибровка полётного контроллера
- GPS-навигация — удержание позиции и полёт по маршруту
- Телеметрия — передача данных в реальном времени
- Видеопередатчик — FPV-полёт с передачей изображения
